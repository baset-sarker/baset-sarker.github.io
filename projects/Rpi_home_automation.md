#### Development of a Raspberry Pi-Based Home Automation System  

**Abstract**  
<div style="text-align: justify;">
Home automation is designed to control appliances and security systems automatically through technology. Safety, convenience, and ease of life are the primary motivations for this development. This work presents an **internet-based home automation system** using a Raspberry Pi, allowing homeowners to control access remotely from anywhere in the world. The system is designed to be cost-effective and energy-efficient, offering benefits in electricity consumption and convenience.  
</div>  

**Project Description**  
The proposed **Home Automation System** consists of the following components:  
- **Hardware:** Raspberry Pi, PIC microcontroller, relays, home appliances (lights, fans, AC, heater).  
- **Software:** Web2py framework for web control, Python for GPIO control, Android app for remote access.  
- **System Features:**  
  - Remote access via a dedicated **Android app ("RPi Home Automation")** or web interface.  
  - GPIO-controlled relay switching for appliance automation.  
  - Secure authentication for authorized users.  
- **Validation:** The prototype was successfully tested with three AC loads, achieving efficient remote control.  
- **Open-source:** The system design and methodology are publicly available for further research.  

**System Overview**  
- The Raspberry Pi acts as a **web server**, allowing remote control.  
- GPIOs on the Raspberry Pi control relays that switch home appliances on/off.  
- A **high-voltage control unit** ensures safety while operating 220V AC loads.  
- The user accesses the system via a web browser or **Android app**.

**Results**  
- **User Convenience:** The system allows remote operation via a smartphone or computer.  
- **Energy Efficiency:** Expected to reduce electricity consumption by **10%**.  
- **Security Features:** Controlled access ensures only authorized users can operate appliances.  

**Conclusion**  
<div style="text-align: justify;">
This research presents a cost-effective, **Raspberry Pi-based home automation system** that enables remote control of household appliances. The system is particularly beneficial for individuals with disabilities, offering hands-free control. Future improvements may include **Wi-Fi integration**, **voice commands**, and **expansion to office/building-wide automation**.  
</div>
